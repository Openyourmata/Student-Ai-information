Curriculum Matrix

Age-Appropriate Learning Pathways

Structured milestones designed to cultivate technical curiosity gradually from visual interfaces to practical software engineering.

Elementary (Grades 1-5)

Visual Foundations & Pattern Recognition

Focus: Conceptual intuition through interactive tools

Young learners discover how machine learning recognizes drawings, audio inputs, and images. They explore how training data shapes model decisions.

  • Google Quick, Draw!: Real-time neural network doodle recognition.
  • Code.org AI for Oceans: Interactive simulation of data labeling and bias.
  • Machine Learning for Kids: Connecting custom classifiers into Scratch projects.
Middle School (Grades 6-8)

Mobile Applications & Logic Systems

Focus: Functional applications and logic bridging

Students build interactive applications that run on mobile devices, train webcam classifiers, and begin foundational programming logic.

  • MIT App Inventor: Building vision-enabled smartphone apps with visual blocks.
  • Google Teachable Machine: Training image, audio, and pose models in-browser.
  • Elements of AI: Conceptual introduction to search, probability, and ethics.
High School (Grades 9-12)

Code Implementation & Capstone Projects

Focus: Python scripting, neural networks & portfolio builds

Students implement algorithms in Python, train neural networks using PyTorch, participate in hackathons, and build portfolio pieces.

  • Harvard CS50 AI: Foundations of search, knowledge representation, and machine learning.
  • Fast.ai Deep Learning: Top-down practical neural network training.
  • Hack the Hood & Hack Club: Youth cohorts, developer fellowships, and collaborative hackathons.
Featured Organization

Hack the Hood: Pathways in Tech & Data Literacy

Hack the Hood is a nonprofit organization providing underrepresented youth and young adults (ages 14-25) with foundational training in data literacy, Python, and artificial intelligence. Participants receive complimentary laptops, tech stipends, and dedicated industry mentorship to support their technical trajectory.

Community Best Practice for Student Developers

When asking technical questions in developer communities, provide a concise summary of what you are building, the code or notebook link, and the specific error message encountered. Clear, thoughtful questions receive prompt and helpful responses from mentors.
